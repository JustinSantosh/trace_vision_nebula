    About this workspace

    Local investigator interface for vehicle traceability from CCTV clips. The interface reads stored results and evaluation files from this repository’s FastAPI service.

    Evidence first

    Unknown plate characters stay as ?. Candidate scores are ranking scores, not probabilities. No owner contact information is shown.

    Current limitations

    Engine status loads from the local API.

    The pipeline exposes coarse job status only; inner stages are not live progress. Evaluation figures reflect the stored labelled set and robustness variants.
